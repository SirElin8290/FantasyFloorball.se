# FantasyFloorball.se

Fantasy manager platform for Swedish floorball, built on real match data and statistics.

## Pilot 2026/27

The first technical pilot is designed for Herrar Division 2 Värmland. The initial repository contains the public landing page and visual foundation for the product.

## Stack

- Next.js 16
- React 19
- TypeScript
- PostgreSQL/Prisma planned for application data

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
